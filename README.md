# imping-runtime

What code generated by the imping toolkit calls into: it finds each module in the running process, checks it's the build the bindings were made for, and backs the generated globals and hooks. `Module`, `Global` and the string types also work without generated code.

```toml
[dependencies]
imping-runtime = { git = "https://github.com/WoefulWolf/imping-runtime" }
```

```rust
use imping_runtime::{Build, Global, Module};

static TARGET: Module = Module::new(
    "target.exe",
    &[Build { timestamp: 0x64b8f2a1, image_size: 0xa2b000 }],
);
static GRAVITY: Global<f32> = Global::new(&TARGET, 0x3a1200);

unsafe { TARGET.init() }?;
GRAVITY.write(4.9);
```

[API docs](https://woefulwolf.github.io/imping-runtime/) · Early development, Windows x64 only for now.
