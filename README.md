# imping-runtime

Runtime support for code generated by the imping modding suite. It finds each module in the running process, checks it is the build the bindings were generated from, and backs the generated globals and hooks. Generated bindings depend on this crate and nothing else; it can also be used on its own for module identity checks and globals.

Status: early development, not published. Windows x64 only for now; on other platforms it compiles, but `init` reports that the platform is unsupported.

## Development

The crate depends on the sibling `imping-hook` repository by relative path, so check it out next to this one.

Run all checks (formatting, clippy, tests, docs) from the repo root:

```powershell
powershell -ExecutionPolicy Bypass -File scripts/check.ps1
```
